SMC for Stochastic Volatility Filtering

Particle filters for daily S&P 500 volatility, when the return and the volatility of the same day move together.

    The model

    Each day j has a return Rj, observed, and a log-variance Xj, hidden. All three models share

    Rj = a + eXj/2 ηj
    Xj+1 = μ + φ (Xj − μ) + σX ξj+1,   ηj, ξj ~ N(0, 1)

    and differ only in how the return shock η is correlated with the volatility shock ξ:

    • (i)No correlation. Volatility moves on its own.
    • (ii)Next day, corr(ηj, ξj+1) = ρ. A fall today raises tomorrow's volatility: the classical leverage effect.
    • (iii)Same day, corr(ηj, ξj) = ρ. The shock that lifts today's volatility also moves today's return, so the one-day forecast is skewed to the left.

    Parameters are estimated on 2000–2015 by maximizing a particle estimate of the likelihood. The 5-minute realized volatility √RV is never used by the filter; it only serves as a yardstick.

    Run the particle filter

    The filter below runs in your browser over all 5358 days. In model (iii) the day's return says a lot about that day's volatility shock. The bootstrap filter ignores this and proposes ξj from N(0, 1). The guided filter proposes from N(ρ zj, 1 − ρ²), with zj the return scaled by the predicted volatility, and corrects in the weights. Both are run on the same days; compare their effective sample size (ESS).
